【GitHub Pagesで公開】
1. 新しいリポジトリ toketsu-toshi-x (Public) に上記ファイルと assets/ フォルダをアップロード。ZIPをそのままアップロードしない。
2. Settings > Pages > Build and deployment で Deploy from a branch を選択。
3. Branch = main、Folder = /(root) にして保存。
4. 公開後は https://budouumibudou.github.io/toketsu-toshi-x/#extra2 で新しい番外編を確認。

新しいリポジトリ名が異なる場合、index.html の og:image で指定されたURL（toketsu-toshi-x/assets/og.jpg）を変更してください。
元の toketsu-toshi リポジトリは変更しません。
